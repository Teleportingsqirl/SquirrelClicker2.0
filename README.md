# SquirrelClicker2.0
A sequel to the hit game squirrel clicker. 

Squirrel Clicker 2 is an Idle Incremental Clicker game that revolves around squirrels. 

Currently in very early developement, hoping for a steam release eventually (once we scrape together 100$). 

We plan to provide a complete enjoyable gaming experience for all squirrel and squirrel clicking fans. 

We hope this game is transformative and complete in its scale and effort, however we are using the godot engine for the first time, so it may take some getting used to. 

The manual for squirrel clicker 1 will be available on the steam page upon release, providing furthur insight into the story, along with cutscenes and expositional dialougue or achievements. 

Code, music, and sound effects by Griffin Crooks Bourassa, art and graphic design by Finley McManus Euler.
